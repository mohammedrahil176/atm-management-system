# ATM Management System

A Flask-based ATM Management System.

## Features
- Login/Auth
- Dashboard
- Cash Withdrawal, Deposit, Balance, Transfer
- Mini Statement, Change PIN
- Admin Panel

## Setup
1. `pip install -r requirements.txt`
2. `python app.py`
